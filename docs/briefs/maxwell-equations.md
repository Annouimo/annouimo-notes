# 麦克斯韦方程组：制作说明（第三轮审阅修订）

## 核心问题与读者

**为什么四条方程能够统一经典电磁学？**

读者具备高中微积分、向量、静电场、电势、磁通量与电磁感应的基础；但尚未学过梯度、散度、旋度、微分形式。讲义必须让读者参与推理，而非陈列概念和公式。

本篇遵守已经审阅确认的 [学习与讲义制作原则](../learning-principles.md)。依据作者在 2026-11-20 至 21 日的两次手工修改：**偏导数要从逐方向变化切入；两变量同时变化需要切平面图；全微分先由局部线性叠加解释，再“发现”梯度；借等势面和高中电势知识说明梯度方向；有向面积与散度都需要独立图解。**

## 2026-11-21 作者最新提交的修订重点

- 不能把三维场直接画成平面矢量场而没有解释；图解应明确左侧一维图与三维空间箭头的区别。
- 全微分图需同时呈现原函数曲面、切平面与辅助参考平面；采用 (2,1) 点让两个偏导系数分别是 4 与 2，避免无意义的巧合。
- ∇ 和其他算符不得凭空出现：分别从梯度、散度、旋度的几何定义引出紧凑写法，并解释其为形式微分算符。
- 电势案例从梯度关系开始用，画平行、垂直、任意斜向位移及投影；线积分先借静电场再转一般梯度基本定理。
- 图解需有完整场背景、清晰文字与一个局部关注对象；二重积分号、积分域、曲面法向、环量符号首次出现均要解释。
- 散度定理紧随散度，斯托克斯定理紧随旋度，后面只做归纳回顾。
- 微分形式从任意的一个、两个、三个方向位移与点积/叉积/混合积切入，后才介绍坐标微分和楔积；外微分优先从小区域边界密度的几何过程引入。
- 麦克斯韦四式的教学起点应按高中实际课程范围：点电荷库仑定律、磁通量、法拉第电磁感应电动势、奥斯特实验与电容 C=Q/U；安培环路定律、高斯电场定律不能当作已经学过的知识。
- 电磁波先讲后两条旋度方程的直观联系，并用波峰平移图解释 f(x−vt)，再作简短的导数消元。

## 教材核对（避免凭印象捏造前置知识）

- 人教版必修第三册：磁场与磁感线、奥斯特实验和安培定则；电容 C=Q/U，理想平行板电容与面积、距离相关。原版课本参考：https://r2-ndr.ykt.cbern.com.cn/edu_product/esp/assets_document/dcd8cc6b-5380-4008-a2d0-a061f24d34dd.pkg/pdf.pdf
- 选择性必修第二册及相关教材：法拉第电磁感应定律定量表达常用 |ℰ|=n|ΔΦ|/Δt（平均电动势大小），固定回路与方向约定后再写成瞬时带符号式。国家课程标准参考：https://www.pep.com.cn/xw/zt/rjwy/gzkb2020/202205/P020220517520664858048.pdf
- 不假定读者已经学过麦克斯韦形式的高斯电场定律、定量安培环路定律或电容器位移电流。

## 本轮落实的教学顺序

1. 从高中 E(x) 图到矢量场，明确标量场、矢量场与不同输入输出维数；删除矩阵和雅可比支线。
2. 二元偏导数 → 两变量同时变化的疑问 → 切平面的平行四边形与高阶误差 → 全微分 → 点积形式与梯度；等势线解释方向，静电势联系物理。
3. 从 U=Ed 到曲线积分和梯度基本定理，解释同一路径的局部变化为什么能望远镜求和。
4. 磁通量从 BA 到 BAcosθ，引入面法向和有向面积，构造曲面积分。
5. 微小盒子左右两面的通量差 → 导数 → 散度，补充点电荷周围局部零散度图。
6. 小矩形上下左右边的环量差 → 旋度，特别讨论圆形场线与局部旋度不同。
7. 小面片和小盒子边界抵消 → 三个积分定理；借相同边界导入电容器两张曲面。
8. 从点线面体测量 → k-形式、外积 → 外微分 → 广义斯托克斯定理；包含简短线积分拉回示例。
9. 从高斯定律、磁场无源、电磁感应与安培–麦克斯韦修正逐条导出四条局部方程。
10. 从无源真空的两条旋度方程导出波动方程和光速；最后讨论约束与演化及适用边界。

## 数学与物理检查点

- 函数的一般局部变化仅能由可微性保证为线性近似；二元函数上的平行四边形必须画在**切平面**而非非线性曲面上。
- 静电场 E=−gradφ 及路径无关性只在适用条件下成立；法拉第方程适用固定回路的写法。
- 对点电荷，场外普通点散度为零；源点用广义函数或积分高斯定律处理。
- 环形场线不意味着每一点旋度非零；穿过电流的回路与仅在无电流区域内的小环不同。
- 形式次数不等于楔积符号数；1形式/2形式与向量场的对应依赖欧氏空间的度量和定向。
- 电容器用理想模型解释位移电流；S₂ 需绕开极板到间隙，展示的是曲面母线/剖面，不是实体薄膜。
- Maxwell 的微观形式与物质中的宏观形式须区分；演化需配合守恒、初始和边界条件。
