# 麦克斯韦方程组：讲义制作说明

## 定位

**核心问题：为什么四条方程能够统一经典电磁学？**

面向具备高中物理、一元微积分、向量与点积基础的初学者；不预设已经理解梯度、散度、旋度、微分形式、高斯电场定律或安培环路定律。依照 [学习与讲义制作原则](../learning-principles.md)：以理解为中心，先解释问题为什么出现，再用图像与推导建立结论；不凭空展示新符号，不用代数机械性替代几何直觉。

## 当前有效的教学主线

1. **场的语言**：从一元的 E(x) 到三维矢量场与标量场。
2. **梯度与线积分**：二元偏导 → 在 A=(2,1) 的切平面上沿两个坐标方向移动、竖直高度可加 → 全微分与梯度；用电势的分量斜率解释静电场 E=−∇φ；从静电势差引出曲线积分及梯度基本定理。
3. **面积、通量、散度**：从 BAcosθ 与面片法向引入带符号通量、曲面积分；从极小长方体对面通量之差引出散度，再通过公共面相消引出高斯散度定理。
4. **环量、旋度**：从逆时针小矩形边界的贡献差引出旋度，再通过公共边相消引出斯托克斯定理；强调圆形场线不必意味着处处有旋度。
5. **微分形式与统一的求导**：先提出三维中标量/向量/叉积表达不整齐的原因；**从已学过的全微分出发**，把 df_A 看成接收任意位移向量、输出一阶线性预测的映射。位移不限于“无穷小”，但近似误差随位移缩小而减小；dx=d(x) 是坐标函数的微分，dx(u)=u_x，且对坐标函数预测就是准确增量。
6. 将1-形式视作**测量规则，而非具体微元**；扩展为交替多线性的2、3-形式。由有向面积的二阶行列式引出形式的楔积，三阶行列式说明体积。多重向量只放入拓展折叠内容，不作为必经主线。
7. **外微分与广义斯托克斯定理**：先根据系数全微分与楔积建立规则，亲手算出1-形式上的 Q_x−P_y 和2-形式上的 P_x+Q_y+R_z，并与早先旋度/散度的几何测量比较；再用混合偏导交换定理（解释连续性条件）与楔积反对称推导 d²=0。通过有向线段“终点减起点”、矩形各顶点带符号抵消解释 ∂²=0；**明确偏导记号 ∂f/∂x 与取边界算子 ∂S 不相同**，并用广义斯托克斯定理说明积分对应。
8. **物理四条规律**：从点电荷库仑定律与球面积抵消引出高斯定律，再用细锥、倾斜面片和叠加原理推广，最后从体积电荷密度进入电场散度；磁通量无源以磁矩/磁畴为直观；固定回路的感应电动势给出法拉第定律；奥斯特实验、稳恒电流与充电电容器两张同边界曲面，引出安培–麦克斯韦定律及位移电流。
9. **电磁波**：无源真空的两条旋度方程 → f(x−vt) 平移 → 波动方程 → v=1/√(μ₀ε₀)，代入真空常数与光速比较；再将同一行波代回法拉第定律，说明 E、B 同相且振幅满足 E₀=cB₀。最后说明四条方程的适用边界、初始/边界条件及洛伦兹力。

## 数学与物理审校底线

- 切平面线性预测与实际函数增量必须区分。dx 作为微分形式与作为初等微积分微元的关系需明确，不能把它们视作偶然重名的两种对象。
- ∇ 是形式微分算符；一般的梯度/旋度/散度对应外微分需要欧氏度量与定向等附加结构。
- 静电场的 E=−∇φ 及路径无关性不能无条件推广到变化磁场。移动导线与固定回路的感应电动势需要区分。
- 点电荷源点不能直接使用普通导数代入微分高斯定律；磁单极未被确认而不是逻辑上已被否定。
- 安培–麦克斯韦电容器讨论依赖忽略边缘效应的理想模型。应明确传导电流与变化电通量，不让积分依赖任意选取的跨越曲面。
- 真空平面行波里的 E₀=cB₀ 是由耦合方程得出，不是任意静态或叠加电磁场都满足。四条方程要结合源、电荷守恒与适当初边值条件理解。
