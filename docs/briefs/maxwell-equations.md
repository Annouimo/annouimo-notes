# 麦克斯韦方程组：制作说明（第二轮）

## 核心问题与读者

**为什么四条方程能够统一经典电磁学？**

读者具备高中微积分、向量、静电场、电势、磁通量与电磁感应的基础；但尚未学过梯度、散度、旋度、微分形式。讲义必须让读者参与推理，而非陈列概念和公式。

本篇遵守已经审阅确认的 [学习与讲义制作原则](../learning-principles.md)。依据作者在 2026-11-20 至 21 日的两次手工修改：**偏导数要从逐方向变化切入；两变量同时变化需要切平面图；全微分先由局部线性叠加解释，再“发现”梯度；借等势面和高中电势知识说明梯度方向；有向面积与散度都需要独立图解。**

## 本轮落实的教学顺序

1. 从高中 E(x) 图到矢量场，明确标量场、矢量场与不同输入输出维数；删除矩阵和雅可比支线。
2. 二元偏导数 → 两变量同时变化的疑问 → 切平面的平行四边形与高阶误差 → 全微分 → 点积形式与梯度；等势线解释方向，静电势联系物理。
3. 从 U=Ed 到曲线积分和梯度基本定理，解释同一路径的局部变化为什么能望远镜求和。
4. 磁通量从 BA 到 BAcosθ，引入面法向和有向面积，构造曲面积分。
5. 微小盒子左右两面的通量差 → 导数 → 散度，补充点电荷周围局部零散度图。
6. 小矩形上下左右边的环量差 → 旋度，特别讨论圆形场线与局部旋度不同。
7. 小面片和小盒子边界抵消 → 三个积分定理；借相同边界导入电容器两张曲面。
8. 从点线面体测量 → k-形式、外积 → 外微分 → 广义斯托克斯定理；包含简短线积分拉回示例。
9. 从高斯定律、磁场无源、电磁感应与安培–麦克斯韦修正逐条导出四条局部方程。
10. 从无源真空的两条旋度方程导出波动方程和光速；最后讨论约束与演化及适用边界。

## 数学与物理检查点

- 函数的一般局部变化仅能由可微性保证为线性近似；二元函数上的平行四边形必须画在**切平面**而非非线性曲面上。
- 静电场 E=−gradφ 及路径无关性只在适用条件下成立；法拉第方程适用固定回路的写法。
- 对点电荷，场外普通点散度为零；源点用广义函数或积分高斯定律处理。
- 环形场线不意味着每一点旋度非零；穿过电流的回路与仅在无电流区域内的小环不同。
- 形式次数不等于楔积符号数；1形式/2形式与向量场的对应依赖欧氏空间的度量和定向。
- 电容器用理想模型解释位移电流；S₂ 需绕开极板到间隙，展示的是曲面母线/剖面，不是实体薄膜。
- Maxwell 的微观形式与物质中的宏观形式须区分；演化需配合守恒、初始和边界条件。
