# 麦克斯韦方程组：制作说明

## 任务
沿用 why-notes 已有 Astro/MDX、KaTeX、正文目录、深浅主题与卡片排版，制作第二篇讲义草稿。用户先审阅分支预览，明确同意后才合并 main、正式发布。

## 核心问题
为什么四条方程足以统一如此多的经典电磁学规律？

## 解释顺序
1. 从高中 E(x) 图像切入：场是三维空间与时间上的函数，函数不等于固定矩阵。
2. 从多元全微分到梯度基本定理；通量与散度；环量与旋度。
3. 展示局部定义与整体积分定理源自共同的边界抵消机制。
4. 微分形式按输入向量的个数分层；外微分统一梯度、旋度、散度；广义斯托克斯定理。
5. 两个场 × 散度与旋度：电场和磁场的源汇与环量。
6. 充电电容器解释安培–麦克斯韦修正；从无源真空旋度方程导出波动方程。
7. 最后才回答约束/演化、统一性与适用边界。

## 可视化
- 局部矢量场：在三个解析可计算线性场之间切换，比较散度和旋度；固定坐标不自动动镜头。视觉为直观演示，不把有限箭头当证明。
- 充电电容器：同一回路 C 下切换 S1/S2 的侧视剖面，阐明截断传导电流与位移电流的关系。S2 为曲面剖面示意，不冒充精确三维拓扑。
- 电磁波：手动改变时间相位，观察同相的 E_y 与 cB_z 分量的传播；二维曲线为分量示意，不当作三维轨迹。

## 数学审阅提示
- 适用微观真空形式；宏观物质需要本构关系。
- 同心球推库仑律需球对称与适当边界条件。
- 固定回路感应定律不能直接替代运动回路的完整电动势。
- 理想电容器曲面等式需理想化与边缘效应说明。
- 外微分次数按输入向量数，不按外积符号数。
- 矢量与微分形式对应依赖内积/定向；形式的外微分不要求雅可比矩阵作为前置知识。
- 演化方程要配合初值、边界、电荷守恒。
