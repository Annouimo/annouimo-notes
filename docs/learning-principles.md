# 学习与讲义制作原则

状态：**修订草案，待人工审阅**。本文件沉淀跨主题经验；具体讲义的教学路线、图解和未决问题记录在 `docs/briefs/`。

1. **学习先于产出。** 讲义是检验理解、留下解释的成果，不以赶进度或堆砌内容为目标。
2. **面向尚未理解的读者。** 明确前置知识；从熟悉的例子和真实疑问出发，依次经历**提出问题 → 建立图景 → 参与推理 → 得到概念与公式**，而不是先陈列定义。
3. **简洁，但不跳步。** 删除重复表述和机械计算，保留新概念成立所需的关键推理、例子与解释。篇幅服从理解，不以缩短文章为目标。
4. **以原稿的教学意图为准。** 保留有作用的提问、类比、解释顺序及制作备注；科学性错误要修正，重要例子的删改和教学路线的调整须先讨论。AI 辅助打磨，不把原稿当作仅供提取知识点的材料。
5. **图解参与推理。** 先找出文字与公式难以跨越的理解障碍，再设计准确、清楚、可观察的图；必要时让读者先观察，再由正文推导。静态图足够时，不强求交互。
6. **交互只服务一个明确问题。** 任务、图像、操作和反馈尽量同屏；保留可审查的数学依据。有限实验展示机制，不代替全局证明；兼顾触屏、键盘与小屏。
7. **借助已有知识搭桥。** 尽量复用读者熟悉的数学、物理情境及本篇已建立的概念；首次出现的陌生符号和术语及时解释，避免概念突然跳跃。
8. **先审阅内容，再打磨界面。** 正文保持单一来源；依次检查科学性、解释连续性、图解有效性、符号与排版，再预览、人工审阅、决定发布。优先复用现有站点成果，避免无收益的样式重构。
9. **用独立表达检验学习。** 读者合上讲义后应能自行解释核心问题、处理反例；适当间隔后再检验，不能把“读起来顺畅”当作真正掌握。

维护约定：只保留经过实践、可迁移的核心原则；修改须经人工确认。优先合并或替换旧条目，避免持续堆积。
